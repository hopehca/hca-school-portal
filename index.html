    Utilisateurs et accès

    Vous êtes l'administrateur : seul vous pouvez modifier les noms, profils, finances et supprimer. Choisissez le rôle de chaque personne.

    Administrateur : tout. Saisie des présences : marque les présences, lit le reste. Lecture seule : consulte seulement.

    Pour ajouter une personne : dans Supabase, Authentication, Users, Add user. Elle apparaît ici après sa première connexion.

    Anniversaires

    Une carte d'anniversaire en PDF pour chaque élève et chaque professeur. Les dates viennent des profils.

    JourNomÂge

    Une page web ne peut pas envoyer de message toute seule : téléchargez la carte, puis envoyez-la par courriel ou WhatsApp.

    Année scolaire

    L'année choisie apparaît sur les rapports et les PDF. Les présences déjà saisies restent enregistrées à leur date.

    Les classes, les professeurs, les élèves et leurs profils sont conservés. Seule l'année change. Téléchargez d'abord une sauvegarde ci-dessous.

    Sauvegarder

    Téléchargez une copie de tout : classes, professeurs, élèves, profils, photos et toutes les présences. Gardez le fichier en lieu sûr (clé USB, courriel à vous-même).

    Restaurer

    Rechargez un fichier de sauvegarde. Cela remplace les classes, élèves, profils et présences actuels.

    Alerte : 2 absences ou plus dans le mois

    Le message s'ouvre déjà rédigé dans WhatsApp ou Gmail. Relisez-le puis appuyez sur Envoyer dans cette application. Si rien ne s'ouvre, copiez le texte et collez-le dans votre messagerie.
